# 当前节点文本智能识别本地实施报告

## 范围

- 当前可编辑审核节点的活动处理人主动粘贴文本并触发识别。
- `businessApi` 重新授权、执行账号级限流并签发五分钟单次内部票据。
- 独立 `nodeTextParser` 调用 CloudBase AI+ 托管模型，只接收原文与当前节点字段定义。
- 小程序展示候选预览；已有值默认不覆盖，确认后仅写本地表单。
- 默认每账号每个上海自然日 300 次，每分钟 10 次且同账号单飞；服务端配置范围为 `1..1000`。

## TDD 与安全证据

- 覆盖伪造、重放、过期及绑定不一致票据。
- 覆盖提示注入、未知字段、重复字段、稀疏数组、继承属性、访问器属性、危险正则和损坏模型输出。
- 覆盖单选/多选精确优先、0.5 模糊阈值、单选近似歧义人工确认、最多 100 个语义候选和选择项不越界。
- 覆盖与保存进度一致的活动账号关系授权、返回前节点版本/字段摘要复核，以及模型结果在解析函数、`businessApi` 和客户端三道边界的字段约束校验。
- 覆盖损坏日期计数、未来计数、底层读取失败与不完整单飞锁的额度失败关闭；页面取消、离开、账号/节点/版本/表单修订均会丢弃迟到响应并清空原文。
- 数据库只保存哈希票据绑定与用量计数，不保存原文或候选；日志只记录稳定错误分类。

## 依赖审计与未验证边界

`nodeTextParser` 锁文件执行 `npm audit --omit=dev` 报告 1 个 moderate、5 个 high、0 critical。来源为腾讯 `@cloudbase/node-sdk` / `wx-server-sdk` 依赖链中的 CloudBase 数据库、Axios 与 Lodash；审计建议会降级 SDK，尚未证明兼容 Node.js 16 与当前 AI+ API，因此未自动修改。生产调用使用固定模型组、受限模型名、固定消息结构、五分钟单次票据、8,000 字符上限和严格响应校验，但该依赖风险仍需在部署前结合腾讯支持版本复核。

以下项目仍为 `unverified`：真实 CloudBase AI+ 模型开通与 Token/费用告警、两个新集合的权限与索引、`nodeTextParser`/`businessApi` 部署及 60 秒超时、嵌套云函数身份上下文、空触发器、开发者工具和真机体验。
