# 业务发起人节点负责人及个人工时明细实施报告

日期：2026-08-18

## 交付结果

本次按已确认设计完成以下能力：

1. 每个模板节点可独立选择“固定候选处理人”或“业务发起人作为本节点唯一处理人”。排序后的其他节点保持各自配置，不受前序节点选择影响。
2. 发起人模式在业务创建事务中固化当前活动发起人为唯一处理人；同一节点发起人与审核人重叠时整笔拒绝。
3. 每个处理轮只把工作分钟归属实际提交审核账号；多候选中的其他账号不获得该轮工时。
4. 每张审核票只把响应工作分钟归属实际投票账号；会签中未投票账号不生成个人工时。
5. 日历缺失不阻断业务流转；处理轮和投票保存不可变起止边界，由独立有界游标补算。历史记录缺少新字段时显示“历史未记录”，不伪造为零。
6. 超级管理员运营看板新增逐轮个人工时明细，可展开查看实际投票人；不增加人员排名，不改变既有 CSV 字段。
