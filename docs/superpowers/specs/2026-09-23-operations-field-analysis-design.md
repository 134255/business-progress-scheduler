# 运营看板有效选项与同节点关联分析设计

## 状态与目的

2026-09-23：用户已批准本书面规格、实施计划及完成测试和复核后的 businessApi 发布与小程序上传。已按连续开发方式实现，当前验证、复核及部署状态以 `docs/memory/STATUS.md` 为准；本规格不是上线或五端真机验收声明。

目标是让运营人员只看到实际出现的数据，并能理解同一份售后节点最终结果中分类、品牌、型号、属性及其他选项的真实组合。不是删除历史数据，也不是建立任意跨节点的通用 BI 系统。

## 已核实的现状

- `cloudfunctions/businessApi/lib/operations-field-domain.js` 的 `aggregateUnique` 先枚举每个字段的有效候选并初始化为零，再累计实际值；每个字段按兼容组独立汇总。
- `miniprogram/utils/operations-field-report.js` 与 `pages/admin-operations/index.wxml` 展示全部字段和候选，没有零值隐藏、节点折叠、前十项或关联分析。
- 最终结果和 `operations_field_snapshots` 保留一份节点结果的多个实际选择值，可以计算同节点共现；单字段计数不能反推出组合。
- 历史实例的 `fieldDefinitions` 保留严格联动规则；当前统计投影没有关联元数据，不能只改页面便正确实现商品逐层分析。
- API 与 `operationsAnalytics` 共享四个领域文件，由 `tools/sync-operations-field-domain.mjs` 检查一致性。此次采用独立查询层扩展，不修改共享快照生成协议。
- 当前工作区有上传、卡片与前序节点等既存未提交改动，必须保留；发布前需要与线上版本核对，不能仅凭 Git 差异把全部未提交内容视为本次新增。

## 本轮范围

1. 隐藏零次选项和没有有效填写样本的字段图表。
2. 按模板、稳定节点分组折叠；按出现次数展示前十项并可查看全部。
3. 商品分类、品牌、型号、属性的逐层筛选及实际属性组合统计。
4. 同一稳定节点内两个单选或多选字段的交叉分析。
5. 与当前字段分析同源、同筛选的 CSV 关联统计，保留全类型字段明细。
6. 测试与统一代码复核后发布 businessApi，再上传新版小程序；不自动提交正式审核或发布正式版。

不包含跨节点拼接、销量或故障率计算、提醒功能、模板目录修改、业务数据重写、权限扩大、新集合或定时任务。原运营工时图表和基础 CSV 的日期口径保持不变。

## 统计口径

- 沿用 ADR-0019：实际路线中已完成节点的最终有效结果是一份样本；整条售后线无需已完成。有审核取最终通过来源，无审核取完成反馈。
- 同一节点去重一次；草稿、旧驳回修订、跳过节点不计入。日期按上海节点完成日期解释。
- 隐藏或不适用的字段不进入其填写分母；可见而未填写的字段另计，不把来源损坏或读取失败算成未填写。
- 单选实际值计一次；多选每个去重后的选中值计一次。合法字符串“0”等不是空值。
- 只合并模板、稳定节点、字段和选项语义兼容的版本；不同模板、不同节点或不兼容定义不得因同名而混在一起。
- 不完整来源保留醒目的已核实样本提示，不宣称总体完整；完整报告继续拒绝导出。范围过大明确提示缩小范围，不能静默截断。
- 所有次数和比例标注“节点样本”，不能把多选选项次数总和标成售后总数，也不能宣称是故障率。

## 展示与交互

### 有效字段概览

- 每个节点为可展开区域，初始折叠并显示有效字段数及样本提示。没有正计数的字段不渲染图表。
- 选项按次数降序排列，同次数采用确定性标签顺序；默认十项，展开后可查看其余有效项。
- 前十项仅是呈现上限，样本分母、占比与导出不受影响。空范围显示“当前条件下暂无有效选项记录”。
- 未填写计数只作为有样本字段的辅助信息；全部为空时不再生成一长列空图表。数据错误提示独立于是否存在图表。

### 商品关联分析

- 使用历史实例中经过校验的 `optionLinkage` 识别组和字段顺序，不通过“品牌”“型号”等文字猜关系，不读取当前可变模板替代历史实例。
- 首先展示实际出现的分类；选中后展示该分类内实际出现的品牌，再展示对应型号。显示当前条件及返回上一级、重置入口。
- 更改上级条件立即清除下级选择与过期结果。关联筛选属于字段分析区域，不改变原工时图表的统计口径。
- 选择型号后分别展示适用属性的分布，另有“属性组合”视图。五列属性保持各自稳定字段身份，不因为中间不适用而错位。
- 组合来自同一节点的实际最终选择，不枚举模板全部允许组合，不对独立属性计数作乘积推算。
- 每个组合只对该节点计一次；分母为该视图全部必要维度均适用且已填写的匹配节点数，同时说明排除的未填写样本。
- 对没有严格联动组的历史模板仍可查看单字段和双字段统计，不伪造商品层级。

### 同节点双字段分析

- 先定位模板和稳定节点，再选择两个不同的单选或多选字段；禁止选择其他类型、不同节点或不兼容版本的字段对。
- 以紧凑组合列表呈现“字段 A 的值 / 字段 B 的值 / 出现次数 / 有效样本占比”，移动端不强制使用宽矩阵。
- 一个维度未填写或不适用的节点不进入该字段对的有效分母；未填写与不适用数量分开说明。
- 多选字段对按同一节点内实际选中的值对计数。同一值对在同一节点最多一次；多个值对的占比合计可能超过 100%，页面和导出明确说明。
- 一个节点贡献多个实际多选值对是共现统计，不代表这些选项构成因果或一一对应关系。
- 关联条件跨字段使用 AND；本轮每个条件只选一个精确值，多选字段按是否包含该值匹配，不新增复杂条件表达式。

## 服务端与客户端边界

### 服务端

- 新增独立的受保护关联分析入口 `getOperationsFieldAnalysis`；沿用现有账号和售后关系授权、最终来源证明及返回前复核。
- 原 `getOperationsFieldSummary`、`getOperationsFieldFilters` 及未声明新版协议的报告请求保持兼容，后端先上线不能破坏旧体验版。
- 独立纯分析模块负责非零投影、实际组合累计、筛选、排序、分母与导出关联行；页面不重算组合、不读取全部明细。
- 分析目录仅包含授权样本中可核实的字段和关联组元数据。关联信息来自对应已核实实例定义，并绑定其来源摘要；不得将未经校验的预读定义附加到一个已验证快照上。
- 不向客户端暴露完整商品规则矩阵、非选项字段内容、账号原始标识或凭证信息。
- 保持 `operations_field_snapshots` 的 schemaVersion、字段结构及 sourceDigest 语义不变。查询时生成关联描述，不新增持久化关联缓存，不要求发布 operationsAnalytics。
- 最多 2000 个字段节点，沿用既有售后与原始扫描边界；关联条件最多八个，双字段维度恰好两个。累计组合贡献上限 50000，超限明确报范围过大；不先生成无界笛卡尔积再截断。
- 分页返回最多 50 个分析条目，采用绑定账号、规范化筛选、维度、来源摘要与顺序的防篡改短期游标；切换条件不能继续旧分页。展示前十项使用同一排序序列，不影响总量。
- 异常只返回稳定错误类别，不记录字段实际内容或客户资料。

### 客户端

- 管理页面负责全局日期、模板等既有筛选与协调；字段分析交互放入独立组件/工具，避免继续将组合计算堆入页面文件。
- 节点折叠、前十项和关联展开分别管理状态；折叠不触发写操作，不影响其他统计板块。
- 快速切换条件、分页重试、页面隐藏/卸载、账号切换与权限失效都有请求代际隔离。旧响应不能覆盖新选择或新账号，撤权时清空敏感结果及待发送文件引用。
- 点击展开只加载所需分析，避免同时为所有节点和所有字段对发请求；不会为每张图单独查询业务详情。
- Android、iOS、HarmonyOS、Mac、Windows 共用原生小程序组件，不新增浏览器专属依赖。窄屏采用单列组合卡片，长标签换行，操作入口不能被挤出。

## CSV 兼容与一致性

- 延续单按钮“生成 CSV → 发送 CSV”，仍只允许活动超级管理员导出。
- 新客户端显式请求新版报告；旧客户端未声明新版时仍只接收原记录类型和列协议。
- 保留原 23 列及现有字段列顺序，追加关联维度标识/名称、维度值原文 JSON、组合次数、有效分母、缺失/不适用计数及分析条件 JSON。
- 新增“关联统计”记录类型。以类型区分基础行、全部类型字段明细、单选/多选统计和当前选定的商品组合或字段对统计；不自动枚举所有可能字段对。
- 有关联筛选时，字段明细和字段统计使用同一批匹配节点；其中其他字段类型仍可在明细查看。无关联筛选时继续导出全部符合原字段筛选的最终节点明细。
- 原运营基础行继续使用售后创建日期及原筛选，不暗中改成节点日期或关联节点集；文件中明确记录其独立口径。
- 关联统计使用全部匹配结果，不只导出前十项或已加载页。零次选项不进入新版统计行，但未填写的原字段明细不被删除。
- 报告来源绑定包含关系定义和全部分析条件；生成、翻页或发送前发现条件/会话失效，不复用旧文件。服务端完整来源或权限变化拒绝续页，不输出拼接的新旧数据。
- 延续公式保护、原文 JSON、全页校验后生成、50000 行/12MiB 硬边界和 20 分钟游标有效期。

## 验收重点

1. 全部空值、部分空值、零次候选、合法“0”、来源异常分别得到正确显示；隐藏空图表不隐藏错误。
2. 十一项以上排序、展开和全量导出一致；同次数顺序稳定，筛选后前十项和分母重新计算。
3. 用合成目录验证分类隔离、同名型号不同品牌、属性中间不适用、多属性真实组合，不产生虚构组合。
4. 单选×单选、单选×多选、多选×多选去重计数；缺失与不适用分母，明确超过 100% 的多选占比含义。
5. 不同模板/节点/不兼容版本隔离，兼容版本合并；当前模板变更不能改写历史关联统计。
6. 旧快照被新分析正确消费且后台生成协议不变；无规则历史样本仍可正常使用基础分析。
7. 撤权、账号切换、来源变化、迟到请求、分页失败/重试、导出条件变化和游标篡改均不泄露或混用数据。
8. 图表与 CSV 组合次数、分母、条件逐项核对；其他字段类型只出现在 CSV，基础行口径及旧客户端协议不回归。
9. 边界样本、过多多选共现、超大标签/结果明确拒绝，不取消资源限制，不截断伪装完整。
10. 原上传、审批、卡片、前序节点记录、工时、导出发送交互的全量回归；真实五端使用与云端性能单独记录，不能用 Node 或模拟布局测试替代。

- 若实现证明必须修改共享快照协议、增加集合/索引、扩大业务写入或跨节点统计，则先报告原因与新范围，不顺带执行。
