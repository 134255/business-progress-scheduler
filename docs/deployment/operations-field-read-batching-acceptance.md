## 范围与兼容性

仅优化 `getSummary / getFilters / getAnalysis` 中同一售后的字段快照复核和关联分析末次来源复核。每批最多20个节点、每事务最多22次固定文档读取，最多4个并发工作。当前活动账号与售后关系仍在每批重新读取；每个节点继续逐项检查来源头与分析定义，返回前保留原最终授权。事务成功后才发布请求内部结果，不跨请求或账号缓存授权。

快照缺失或过期继续权威回源；可恢复的来源缺口只影响对应节点，未知错误继续失败关闭。统计口径、选项关联、候选清单、分页、CSV完整权威来源及导出失效规则不变。没有前端、模板、数据、索引、Timer、依赖或资源配置修改，不新增托管服务或费用。
