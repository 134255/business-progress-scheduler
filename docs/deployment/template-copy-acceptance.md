# 模板复制：发布与验收

## 范围

模板管理列表新增“复制”。活动超级管理员确认后，服务端读取原模板已保存的定义，原子创建“原名称－副本”的独立草稿（版本 1），并进入副本编辑页。草稿、启用和停用中的模板均可复制；删除的模板不可复制。当前编辑页尚未保存的内容不参与复制。

复制节点、字段和选项、条件显示/候选项联动、全部流程路由、处理/审核配置、时限、凭证要求，以及独立的卡片展示规则。模板和节点文档编号、节点/字段稳定标识重新生成，所有引用同步重建。副本不自动启用，不包含已有售后、反馈、凭证、分享或统计；原模板及其历史不变。旧线性模板保持其原工作流语义。

失效参与人、配置损坏或源定义在复制期间变化时拒绝创建。源头、全部源节点、当前管理员和参与人的事务读取，以及副本头/节点/审计写入，一并计入现有 100 操作预算；超限提示调整模板，不分批写出半成品。卡片配置与副本同事务提交，不追加第二次保存。

## 发布边界

- 需要更新 `businessApi` 及小程序客户端；不需要更新其他云函数。
- 不新增集合、索引、环境变量、权限或定时器。
- 此文档不代表已获发布授权或已经上线。取得当次发布许可后，保留现有函数配置，先发布后端再上传客户端。
- `businessApi` 包须包含新增 `lib/template-copy-domain.js`，以及修改后的 `index.js`、`lib/template-service.js`、`lib/template-domain.js`、`lib/cloud-template-repository.js`。
- 保留当前工作区其他已有改动，不能用旧函数整包覆盖线上其他已验证功能；按现有部署流程先比对代码并留回退副本。

## 发布后人工验收（未执行）

1. 管理员打开模板管理，对测试用模板点击“复制”；先取消，确认未增加副本。
2. 再确认复制。应显示处理中、阻止重复点击，成功后进入“原名称－副本”的草稿编辑页，版本为 1。
3. 核对节点顺序、全部路由、人员/时限/凭证配置、字段选项和品牌→型号→SKU映射，以及卡片展示字段。
4. 只修改测试副本的名称或某项配置，保存并重开；原模板及既有售后保持不变。
5. 验证启用中的源模板可复制且保持启用；普通账号不能调用复制接口。
6. 网络中断时先刷新列表检查是否已经创建副本，再决定是否重试；不自动重试写入。若仅打开编辑页失败，应提示“副本已创建”，而不是误报复制失败。

不得为验收擅自停用真实账号、改真实客户记录或删除源模板。
