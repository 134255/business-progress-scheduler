# 节点字段次数与完整 CSV 验收

本地实现验收与云端/真机验收分开记录。本文件使用合成数据，不写真实客户资料、身份或文件内容。原 CSV 生成/发送问题已由用户确认通过，本次验证新增字段与次数，不重开旧问题。

## 合成样本与预期

同一模板、稳定节点和稳定字段的三个有效已完成结果：单选 A/A/B，多选 [X,Y]/[Y]/[]。售后整体可仍进行中。另留一个未完成、一个未走路线、一个已被驳回的旧反馈，以及同一结果的重复保存。

- 看板单选 A=2、B=1；多选 X=1、Y=2，填写2、未填写1。不会累加旧轮次和重复保存。
- 增加短文本、长文本、数字0、布尔false、日期、逗号/引号/换行及前导空白的公式样式文本。看板请求不包含这些值；管理员 CSV 的字段明细完整保留，布尔为“否”，多选为可还原 JSON 数组，公式样式内容作为文本。
- 同名但不同模板/稳定字段不合并；仅版本号变化可合并；改变类型、候选项或条件定义必须拆组。隐藏条件字段不计分母，不导出旧分支残值。

## 权限、来源与恢复

- 普通活动账号只看当前有权售后，管理员看全部匹配售后；CSV仍只有活动超级管理员能生成。
- 无审核取发布的完成反馈；有审核取严格对应最终通过轮次；等待人工决定后续但处理已完成可计。缺失最终来源/日期明确为缺口，不伪报0或生成完整文件。
- 删除快照不删除来源：有限候选即时恢复结果；快照过期回读权威来源。后台40条原始候选预算能公平推进第41条，坏记录不阻塞后续，重试不重复累计。
- 请求期间撤权/停用、分页之间来源或筛选改变，必须拒绝或使当前导出失效；游标篡改、过期、跨账号不可使用。
- 普通账号不得从分组、筛选候选、样本数或缺口提示推断无权售后；快照不是权限来源。

## 同一个 CSV

1. 首次点击“导出 CSV”显示进度，全部分页成功才生成文件；原按钮改为“发送 CSV”。再次点击直接打开发送接口；失败/取消有反馈，不在验收中代用户选择接收人或发送。
2. 前23个基础列及其顺序不变；追加记录类型、日期口径、字段内容、选项次数等列。
3. 按记录类型分别筛选“运营基础”“字段明细”“选项统计”。基础记录仍按创建日期/状态，字段记录按节点完成日期和当前字段筛选。
4. 按 fieldGroupId，从“字段或选项原文（JSON）”解码后重新计算单选/多选次数，与本文件选项统计逐项相等。此列的单选/其他字段/统计选项为 JSON 字符串，多选为 JSON 数组（未填写仍依数据状态判断）。原可读列继续公式防护和统一换行；需要精确还原 LF/CRLF、前导符号时使用 JSON 原文列，不能对可读列简单去掉一个撇号。字段/汇总行不重复填写工时，汇总行不冒充某条售后。
5. 改模板、版本、节点、售后、参与人、日期、状态或账号后不能复用旧文件。页面离开后旧请求不得回写；字段统计失败不清空已成功的旧工时图表。
6. 延迟模板A筛选响应，先让模板B开始统计，再返回A，不得清空B或卡住加载。返回仅有记录类型、缺字段标识/内容、非法次数的残缺数据时，不生成可发送文件。
7. 无工时事实但已有最终完成结果时，仍能选择对应售后、实际提交结果的处理人和实际通过票审核人；候选但未实际提交/投票者不能冒充该字段结果的参与人。普通账号撤权后这些候选也消失。
8. 调整日期并点击生成时重新发现历史模板、版本、节点和参与人。仅保留仍有效的选择，不按旧数组下标误选；从空范围扩大到有历史结果也能点击生成，不能被空模板列表锁住。
