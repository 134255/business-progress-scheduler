## 自动验证

- businessApi 全量测试、operationsAnalytics 全量测试、客户端全量测试。
- 新分析、前序节点及原卡片官方 WXML 渲染，WXML 结构、四文件共享 bundle 校验。

## 用户验收路径（五端均待实际验收）

1. 在体验版进入运营看板，生成统计；只出现有记录的节点，默认折叠。展开后零次选项不显示，超过10项有查看全部，比例不随分页变化。
2. 商品关联分析依次选择分类、品牌、型号：不同分类不得混入无关品牌；同名型号按所属品牌区分；型号属性中间空列不得导致列名错位。查看属性组合仅出现真实已提交组合；无适用属性明确提示。
3. 选择同一节点两个字段，检查单选/多选共现、有效填写/未填写/不适用分母与解释；重复选同一字段不得留下原关联结果。
4. 活动普通账号只看自己当前有权的最终节点字段；活动超级管理员可导出。工时全局汇总的既有权限语义不变。切换账号、撤权、隐藏页面后，不得由旧请求恢复敏感内容。
5. 管理员点击导出 CSV 完整生成后再点击同一个“发送 CSV”。CSV 含原基础行、所有类型字段明细、正计数统计及选定关联统计；分析组/条件 JSON 与界面一致。基础行仍按售后创建日期、不跟随字段条件筛选。未填写与不适用区分，失败不能留下可发送半文件。
6. 原生发送面板取消/成功返回有反馈；真正换账号或改筛选后旧文件失效。分析目录缺口/网络失败可独立重试，不清除成功的工时图表，不把缺口当零。
7. 回归原图片/视频/PDF上传、保存进度、提交/审核、卡片摘要、前序节点查看/返回；不擅自在生产创建测试业务或群发通知。

需逐一记录 Android、HarmonyOS、iOS、macOS、Windows 微信实测。当前没有这些设备的实测结果，不标为通过。
