## 重跑

Node.js v24.14.0；无新依赖。仓库根目录运行：

```powershell
node --test tools/capacity/test/*.test.cjs
node tools/capacity/run.cjs --profile smoke
node tools/capacity/run.cjs --profile month --scenario field-summary --max-ms 60000 --max-reads 100000 --max-heap-mb 512
node tools/capacity/run.cjs --profile half-year --scenario history-growth --max-ms 60000 --max-reads 100000 --max-heap-mb 512
node tools/capacity/run.cjs --profile year --scenario history-growth --max-ms 60000 --max-reads 100000 --max-heap-mb 512
```

无参数等于smoke；`--scenario`可单跑。大档仅包含字段/报告/历史场景，不和50账号/2495矩阵做笛卡尔乘积。逐场景独立子进程；默认30秒、20000逻辑读、256MiB V8旧生代上限及heapUsed保护；并非总RSS上限。父进程强制终止挂起子进程、等退出后再开始下一场景。大档本次固定60秒/100000读/512MiB，没有自动提高预算重试。

退出0仅表示所有选定场景ok且complete；1表示存在known_limit/incomplete/test_aborted/error；2表示非法参数。**当前smoke整体预期退出1**：两种报告触及测试读预算，另有一个故意缺来源的场景；不能说smoke全部容量通过。单元测试断言这些限制正确，测试命令可退出0。

- `known_limit`：真实产品现有保护上限；不改上限强行跑通。
- `incomplete`：缺权威来源；不能冒充完整统计。
- `test_aborted`：测量读/时间/内存/事务预算中止或进程被杀；不代表线上业务已失败。
- `error`：未知或不应出现的错误（普通场景的FORBIDDEN/REPORT_CHANGED、任意写入尝试、无明确中止证据的子进程非零退出也属于此类）。不能把未知进程异常或无法辨明的内存崩溃归为正常预算中止；原始错误内容不输出。
- 输出仅白名单数字与固定标签；游标、字段/身份/异常栈不输出。不接受env、URL、账户或客户文件参数。网络入口拦截测试不是操作系统网络沙箱。

- 有效选择快照150节点669读，缺失/陈旧快照969读；源数据一致时字段计数一致。未修改快照或生产恢复任务。

- 10/20/50账号交错仅2节点小样本、每请求独立仓储；相同大小的不同授权集合有不同字段值，逐组核对选项/计数，并以互换账号故障注入证明能发现串读；不能据此承诺50人真实同时上传100MB。
