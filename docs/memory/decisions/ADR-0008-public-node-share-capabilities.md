# ADR-0008：七日公开节点结果快照使用能力令牌

## Status（状态）

已于 2026-08-17 接受。项目所有者确认接收者无需登录或业务权限即可查看分享时固定的节点结果，最长有效七个自然日，并选择小程序公开只读页作为交付形态。

## Context（背景）

节点结果可能包含结构化字段、图片、视频和 PDF。微信只能由用户主动打开原生分享面板选择好友或群，应用不能读取好友列表或代替用户自动发送。普通业务详情要求登录和成员权限，无法满足外部接收者直接查看；直接公开业务或永久文件编号又会绕过现有权限和保留期。

## Decision（决策）

- 每次分享生成至少 256 位随机能力令牌，只授权一个已完成节点的不可变快照。
- 公开页无需登录，不再检查接收者账号；持有令牌即拥有七天只读访问能力。
- 快照正文、字段和值在创建时固化，凭证使用短期 URL，永不公开永久文件编号。
- 有效期固定为服务端创建时刻后七个二十四小时，不接受客户端延长。
- 大量凭证使用最多 40 条一块的独立快照块；发布完成前不可见。
- 原始凭证只增加截至分享到期的保留锁，不复制云文件；保留工作器在锁有效时跳过，过期后恢复原业务或修订保留规则。
- 过期分享元数据由保留工作器有界删除，公开读取对不存在、撤销、到期和损坏统一失败。

## Consequences（后果）

- 分享链接属于短期敏感能力，不能记录到日志、项目记忆或审计正文；用户主动转发后，七天内任何获得链接的人都可查看。
- 必须新增两个仅云函数读写的集合及相应到期、分块索引，并在部署手册中记录。
- 真机分享面板、群转发、视频/PDF 打开、七天到期和清理均需真实微信/CloudBase 验收。
