# ADR-0021：模板内置商品严格组合联动

## Status

2026-09-18 用户确认严格联动、疑问行排除及模板内置方案，并要求直接实施。发布与配置证据以 STATUS 为准。

## Context

商品表的分类、品牌、型号和五列属性必须级联单选。多个型号的属性并非笛卡尔积，独立候选或单父映射会产生实际不存在的组合；五列属性允许中间空列，不能重排其列身份。

## Decision

- 单节点最多一组八字段；首字段保存 `optionLinkage:{schemaVersion:1,fieldKeys,rows}`，每列字典保存在对应单选字段的 `constraints.options`。前三级非空，属性 `null` 表示不适用。同型号组的适用列一致；最多5000行、组及字典256KiB、完整规范化节点512KiB。
- 服务端与客户端使用同步的纯规则引擎，按所有前置有效值筛选；保留仍合法后继、清空非法或隐藏后继。隐藏字段不得提交、计样本或出现在公开投影。单候选仍需用户选择；合法前缀可保存进度，最终提交必须填完适用必填项。
- 整体导入只改变编辑草稿，保留分类/品牌/型号稳定标识和所有无关设置。SKU删除先核对条件、路由及已保存卡片引用；有引用时停止，不能顺带改掉其他设置。成员不能以旧逗号输入框拆分或单独删除、重排。
- 矩阵保留在页面私有内存，不重复进入 `setData`。新字段通过独立临时引用映射稳定键；保存显式携带支持的 `optionLinkageEdit` 及已加载定义摘要，新旧定义任一有规则时均检查，防止旧客户端静默丢规则。
- 历史实例固化自身规则；复制重写组内引用；流程分支不接受组成员。定义摘要覆盖编码，统计兼容与识别失效采用整个组合组的语义，等价字典重排及行重排不拆分统计。
- 统计和CSV只投影最终有效值及其有效候选；检索、卡片、分享不暴露完整目录；识别仅发送当前可选字段，并另行复核整组变化。大数组复制预算仅针对有界字段定义/结果，不放宽报告来源节点上限。
- 离线导入只读Excel已保存缓存值，不重算或连接外部文件；只处理指定类别，明确排除疑问行。真实商品目录和导入JSON不进入Git或项目记忆。

## Alternatives

不建立独立商品库，避免额外集合、权限、网络和历史版本依赖；不为属性生成大量重复条件字段。代价是模板/节点快照更大，规则更新需整体导入，服务端和消费者须同时理解新规则。

## Consequences

不增加集合、索引或Timer，不修改账号/权限；至少更新 businessApi、operationsAnalytics 和客户端后才配置真实模板。不得直接改 template_nodes 绕过模板头摘要，也不得回滚到会丢弃已使用规则的旧版本。真实验收不擅自新建生产测试售后。
