# ADR-0019：最终节点字段统计与同源完整报告

## Status（状态）

2026-09-11 用户已接受产品、权限和书面设计。本地实现、全量测试与独立整体复审通过；部署和实际账号验收仍 unverified，以 STATUS 的最新证据为准。

## Context（背景）

运营看板需按节点显示单选/多选选项出现次数，其他字段仅在 CSV 中查看。现有工时事实属于全局汇总且可能依赖日历补算，不能直接用于普通账号的字段内容计数；全局累计值无法在撤权后安全拆除无权售后。

## Decision（决策）

- 以实际路线上的已完成节点最终有效结果为一份样本；售后整体可尚未完成。无审核取发布的完成反馈，有审核核对最终通过轮次、反馈修订及实际投票者。只读实例字段定义和最终条件结果，不伪造旧记录。
- 按模板、稳定节点、稳定字段、类型及候选项/条件兼容性分组。跨兼容版本可合并；单选非空计一次，多选合法去重项各计一次，隐藏字段不进入分母，空白另计；其他类型不进入看板。
- 新增仅服务端读写的 operations_field_snapshots，确定性节点编号覆盖式保存单选/多选派生。sourceHeader 只是已验证服务器快照的失效键，不是授权或内容签名；权威已发布反馈/审核不可变为其前提。最终 sourceDigest 包含字段内容与精确来源。每次查询在聚合前按当前账号/售后关系授权，并在返回前复核。
- 快照不能证明历史覆盖完整：查询从当前可授权节点发现缺失结果，有限回源恢复；来源异常提示不完整，完整报告拒绝。原有工时事实与完成流程不因派生失败回滚。
- 后台独立 keyset/CAS 游标按原始节点推进，每轮最多40条，工时阶段后另给5秒协作预算；不能取消已在途 SDK 操作，真实超时须发布时核验。只写新派生集合及自己的游标，不改客户记录、权限或定时配置。
- 新报告只允许活动超级管理员使用。单个文件包括运营基础（创建日期口径）、字段明细和选项统计（节点完成日期及全字段筛选）。保留原23列顺序，追加类型/日期口径/字段/次数列；工时不在明细/汇总重复填写。次数由同一份最终字段集合生成，不拼接页面旧统计。
- 游标采用用途隔离 AES-GCM，复用现有服务端检索密钥派生；绑定账号、完整筛选、权威节点/sourceDigest 清单、基础来源清单、报告摘要、偏移与20分钟有效期。无合格密钥明确失败，旧基础协议不受影响。
- 单请求最多2000字段节点；报告最多50000行/12MiB，超限拒绝不截断。完整基础数据按20个售后编号批读，不嵌套调用旧分页。进程内最多3份且总计12MiB的短效私有报告缓存复用投影，续页仍校验字段来源集合、基础记录与当前权限；不持久保存其他字段副本。
- 原单按钮生成/发送交互保留。全部分页成功才生成本地文件；筛选、账号、页面或来源变化后失效，取消/失败/等待超时有明确反馈。
- CSV 原可读列继续使用既有公式保护和换行规范化，末尾另附“字段或选项原文（JSON）”以无损保留字符身份；单选/选项为 JSON 字符串，多选为数组。精确核对次数使用该列与兼容组，避免换行或公式前缀导致明细与汇总标签不一致。客户端按新记录类型验证必填元数据、值和合法计数，残缺行不能生成可发送文件；旧基础行协议不变。
- 筛选候选同样不依赖工时事实：由已核实且获授权的最终结果产生售后及实际参与人候选，参与人姓名取对应不可变节点快照，缺失时使用安全历史占位；不返回原始账号标识。客户端按日期重新发现模板和各维度候选，按值保留仍有效的选择，空范围也可扩大日期重新查询。

## Alternatives（替代方案）

每次遍历全反馈历史会重复解析，且不能直接证明最终轮次；纯全局累计数不能按当前权限筛选；多文件导出增加操作并无法在同一文件核对。因此选择节点派生+有界权威回源、同源完整报告。

## Consequences（后果）

需新集合和查询索引、更新两个函数与小程序，但不自动改Timer或旧数据。旧实例没有独立模板名称快照时不能从名称字符串猜历史名称，只能显示仍可核实的名称或模板标识。大范围仍有与样本数成比例的来源/授权验证成本；本地合成测试不能证明真实云端延迟、上线成功或真机验收。
