# ADR-0022：最终字段关联分析与版本化完整报告

## Status

2026-09-23 用户确认规格及实施计划，授权本地验证、统一复核后发布 businessApi 并上传小程序。实际部署与原生验收见 STATUS。

## Context

原看板平铺所有候选选项，零记录项遮蔽实际数据，且独立字段频次丢失商品和业务字段之间的关联。最终字段快照已包含同一完成节点的有效选中值，但不能把当前模板规则或跨节点同名字段当作历史实例关系。

## Decision

- 新增独立只读分析接口，按节点完成日期聚合当前有权访问的最终结果；仅显示正计数单选/多选，按节点折叠、默认前10项、其余显式分页。未填写与不适用分别计数，多选按节点去重贡献，百分比使用有效填写节点分母。
- 在已验证来源事务中，从历史节点定义生成查询用关系描述；维度身份包括字段兼容语义及条件祖先语义，严格联动组身份包括完整八列组合规则。分类、品牌、型号按前缀过滤，属性保留中间空列身份，组合只统计实际出现的元组。仅支持同节点双字段共现，不推断因果。
- 保持 operations_field_snapshots 的 schemaVersion、sourceHeader/sourceDigest 和旧 worker 结果完全兼容。新增纯 helper 镜像不要求重新部署 operationsAnalytics，不迁移数据、不新增资源、权限或 Timer。
- 分析与导出游标使用独立目的认证，绑定账号、条件、完整候选来源清单及有效期。包括尚未匹配分析条件的候选；续页新增或改变来源须拒绝旧游标。返回前再次校验活动账号、售后权限和历史定义。每页最多50项/512KiB、最多2000候选节点、关联贡献最多50000；超过边界明确缩小范围，不静默截断。
- CSV 显式 reportVersion=2；无版本的旧客户端协议不变。基础23列及售后创建日期口径不变，新列只追加。字段明细保留全部类型；选项统计按严格维度计数，明细和统计共享 analysisGroupId，关联行包含精确维度/值/筛选 JSON。基础行明确不应用字段分析条件，字段及关联行使用相同已核实来源和分析条件，缺口禁止生成完整文件。
- 前端采用独立分析组件，不改变工时图表或原两阶段文件发送。上下文变更立即失效旧结果/文件；原生发送引发 hide 仅清理敏感界面，不改发送任务条件；真实换账号、撤权或改筛选仍拒绝旧回调。

## Alternatives

不在旧快照写入新关系格式，避免额外 worker 部署、回填及原摘要变更；不按字段显示名猜关系，不做跨节点交叉统计，不生成全部字段两两矩阵。代价是查询需要核实历史定义，大数据范围受明确预算限制。

## Consequences

只发布 businessApi 与新版客户端即可启用新路径；旧接口继续支持旧客户端。来源核实不完整或过大时用户需等待派生补齐或缩小条件。模拟渲染与自动测试不等于五端微信原生验收。
