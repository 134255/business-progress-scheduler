# ADR-0020：独立模板草稿复制

## Status

2026-09-18 用户批准增加模板复制。实现与验证状态见 STATUS；上线需单独发布验证。

## Context

模板含节点、字段、条件候选项与流程路由引用，卡片展示又有独立修订号。只复制模板头或使用客户端依次新建再保存展示配置，会留下断裂引用或不完整副本。业务希望复用已保存的配置，而非复用历史售后数据。

## Decision

- 在现有模板管理列表提供受活动超级管理员保护的复制动作；允许复制草稿、启用及停用模板，不要求停用源模板。只接受源模板编号和期望版本，不接受客户端提交复制定义或身份。
- 服务端读取并规范化源定义，生成新模板/节点文档编号与新节点/字段稳定标识，同步重建入口、路由、条件字段和卡片展示引用。保留人员、时限、凭证要求及旧模板原工作流语义。
- 副本默认命名“原名称－副本”，状态草稿、版本 1；卡片配置从新的修订起点开始。元数据只用允许的定义项，不复制启停/删除时间、旧版本、历史售后、反馈、附件、统计或分享。
- 同一个固定文档事务重新校验当前管理员、源头（含独立卡片配置）、全部源节点和参与人，提交副本头、节点及脱敏复制审计。所有操作纳入现有 100 次预算；超限或冲突失败关闭，不拆成可部分成功的写入。
- 客户端确认提示只复制已保存内容；等待期间单飞，取消不写入，账号变化或页面销毁后丢弃旧响应。网络结果不明时提示先检查列表，不自动重复创建。

## Consequences

- 副本可独立编辑，不影响原模板、历史售后和按模板划分的统计。
- 无新集合、索引、Timer 或外部服务；需要发布 businessApi 和新客户端。
- 大量节点/参与人的源模板可能超过复制事务预算；明确报限，不降低校验或偷偷拆分事务。
- 未保存的编辑不纳入复制；发布、真实设备渲染与云端验收不能由本地测试代替。
