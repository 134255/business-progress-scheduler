# 45minup售后小程序首次使用说明

员工操作版 · 适用模板「45minup售后」第 13 版

核对日期：2026年9月20日。依据当前已启用模板和现有页面编写；后续模板更新时，以页面显示的字段、处理人和状态为准。旧售后保留创建时的模板，不一定与本说明相同。

## 1 第一次进入和创建售后

### 先准备好这些资料

管理员分配的账号及初始密码、商品分类／品牌／型号／属性、所属门店、购买日期、订单编号、客户姓名／电话／地址、仓库信息、故障描述，以及必要的照片或视频。页面出现 SN 字段时，还需要商品唯一码。

### 首次登录

1. 用本人的微信打开管理员提供的「45minup售后系统」小程序入口。
2. 输入分配给自己的用户名和密码，点击「登录」。不要使用同事账号。
3. 首次登录按提示设置新密码，再次输入并点击「确认修改」。密码须为 8–64 位，至少包含一个字母和一个数字。
4. 进入首页后，核对左上方问候语中的姓名；不正确时先停止录入，联系管理员。

账号会关联微信身份。更换微信、账号被停用或密码遗忘时，联系管理员处理；不要反复尝试其他人的账号。已经登录的用户可直接进入首页。

### 首页入口怎么用

| 入口 | 用途 |
| --- | --- |
| 新建售后线 | 从启用模板创建一条售后 |
| 待我处理 | 找到当前需要自己录入、执行或补充的售后 |
| 待我审核 | 审核自己负责的待审记录 |
| 进行中／已完成 | 查看自己有权限访问的对应状态售后 |
| 消息通知 | 查看小程序内消息，并进入对应售后 |
| 查看全部 | 查询权限范围内的售后；不是全公司所有记录 |

### 创建第一条售后

1. 点击首页「新建售后线」，选择「45minup售后」。
2. 核对模板名称；「说明」可补充背景或特别要求，不代替后面的结构化字段。
3. 点击「创建售后线」，等待「创建成功」并进入详情。名称和编号由系统生成，不需要手工编号。
4. 在详情中打开当前「售后信息收集」节点，开始填写下一页的资料。

创建成功不等于已提交售后资料。资料填写、凭证上传和提交审核都在节点页面完成。网络异常时，先回列表确认是否已创建，避免重复建单。

## 2 填写售后信息收集

这个节点由售后发起人填写。当前模板共有 20 个字段定义，但条件字段会按选择显示，并非每次都要填写 20 项。页面带「*」且当前可见的字段必须填写。

### 商品必须逐级选择

分类 → 品牌 → 型号 → 属性1 → 后续适用属性

分类只有「人体工学椅、升降桌、灯具、儿童系列」。品牌随分类变化，型号随品牌变化，属性只显示前面选择对应的有效组合；这些商品字段均为单选。

- 选完当前一级，再选择下一项。某型号只需要一两个属性时，其余属性不会显示，不需要补填。
- 修改分类、品牌、型号或前一属性后，重新核对所有后续选择；不再符合联动规则的值会被清空。
- 找不到真实商品或属性时，联系管理员补充模板，不要用相似型号代替。原来的 SKU 字段已不再使用。

### 其余资料填写规则

| 字段 | 填写要求 |
| --- | --- |
| 所属门店 | 单选实际归属门店 |
| 人体工学椅SN(商品唯一码) | 品牌为保友、黑白调、西昊、清闲或永艺时显示；显示后必填，按商品标签核对 |
| 升降桌SN（商品唯一码） | 分类为「升降桌」时显示并必填 |
| 购买日期 | 选择实际购买日期，不用填创建售后的日期代替 |
| 仓库 | 从「一件代发仓、品牌备货仓、现货仓」中单选 |
| 现货门店仓 | 仓库选择「现货仓」后显示并必填 |
| 订单编号 | 原始销售订单号，不是系统生成的 BL- 售后编号 |
| 姓名、电话、地址 | 填实际联系／收件信息；提交前核对，避免错寄 |
| 售后部位 | 多选，可选多个问题部位；当前选项以椅类部位为主，不适用时选「其他」并说明 |
| 具体问题描述 | 必填，写清现象、发生条件、频率及已尝试的处理 |

“具体问题描述”示例（虚构）：坐下后向后靠时，右侧扶手出现异响，约每次后仰都会发生；已检查外露螺丝，仍未解决。不要只写“坏了”或“有问题”。

### 检查后再提交

核对商品组合、订单号、客户联系方式、SN 和问题描述；需要说明现象时附上凭证。点击「提交审核」，看到成功提示后返回详情确认已进入待审核状态。当前模板这一节点需要审核，不能由发起人自行点击通过。

## 3 看懂当前模板的实际流程

先完成「售后信息收集」并通过审核，再进入「售后解决方案提供」。该节点的指定处理人选择「解决方案」，并填写「具体方案描述」，完成后系统只进入所选路线。

| 解决方案 | 后续路线 |
| --- | --- |
| 退货 | 退货方案执行 → 退货单号提供 → 结束 |
| 换货 | 换货方案执行 → 换货退回 → 结束 |
| 更换配件 | 更换配件方案执行；选「配件是否退回＝是」时进入配件退还，否则结束 |
| 赠品补偿 | 赠品补偿方案执行 → 结束 |
| 其他 | 其他方案执行 → 结束 |

### 各节点由谁做和填什么

「指定处理人」指详情页显示的模板预设人员；「发起人」指创建这条售后的账号。无需自行选择或猜测接手人。

| 节点 | 执行人 | 核心内容 |
| --- | --- | --- |
| 售后信息收集 | 发起人 | 商品、订单、客户及问题资料；提交审核 |
| 售后解决方案提供 | 指定处理人 | 解决方案、具体方案描述，均必填 |
| 退货方案执行 | 指定处理人 | 退货地址，必填 |
| 退货单号提供 | 发起人 | 退货单号，必填 |
| 换货方案执行 | 指定处理人 | 换货地址必填；换货单号选填 |
| 换货退回 | 发起人 | 换货退回单号，必填 |
| 更换配件方案执行 | 指定处理人 | 配件单号、配件是否退回，均必填 |
| 配件退还 | 发起人 | 配件退还单号，必填 |
| 赠品补偿方案执行 | 指定处理人 | 赠品单号，必填 |
| 其他方案执行 | 指定处理人 | 其他方案描述，必填 |

当前第 13 版只有「售后信息收集」配置了审核人；其余 9 个节点由处理人「完成节点」后流转，不另行等待审核。10 个节点是全部可能路线，不代表每条售后都要完成全部节点。

末端节点完成后，系统结束该售后。尤其注意：“退货单号提供”“换货退回”完成后就会结束，当前模板没有额外的退款确认或收货验收节点。填写单号应符合实际业务进展，不能把系统结束误认为银行退款或物流签收的证明。

## 4 处理进度审核与凭证

### 处理人每次怎么做

1. 从首页「待我处理」进入售后，核对编号、当前节点及处理人。
2. 打开节点，填写当前可见必填字段，补充「进度说明」和需要保留的凭证。
3. 根据实际进展，选择下表中的操作；等待成功提示，不要上传中退出或反复点击。
4. 返回详情核对状态和当前节点。不能只凭点击按钮就认定已提交。

| 操作 | 用途与结果 |
| --- | --- |
| 保存处理进度 | 保存当前内容，节点仍未完成，不会自动进入下一节点 |
| 标记受阻 | 在「进度说明」写清受阻原因后操作，表明暂时无法推进 |
| 提交审核 | 当前信息收集节点使用；提交后等待审核，页面转为只读 |
| 完成节点 | 当前其余节点使用；通过校验后立即按所选方案流转，末端节点会结束售后 |

当前版本「保存处理进度」和「标记受阻」也会校验可见必填字段，不是允许任意空白内容的自动草稿保存。切勿将未保存的页面内容当作已入库记录。

### 凭证怎么上传和查看

- 手机：点击「选择图片或视频」，从微信提供的相册／拍摄入口选择；电脑微信会先显示「选择本机图片」「选择本机视频」。JPG 与 MOV 走图片／视频入口，不需要先转到聊天再选。
- PDF：点击「选择 PDF」，在微信文件选择窗口中选择可用 PDF。
- 选中文件只是加入待上传列表。点击保存、提交或完成操作时才上传并登记；本轮选中文件合计不得超过页面显示的 120 MB。
- 等待文件登记和本次操作成功；出现「上传失败」时按错误提示处理后重试，不能当作凭证已提交。不要仅修改扩展名伪装格式。
- 提交后在「反馈历史」点文件名查看。需要多个文件时用「顺序下载可用凭证」；已清理或不可用的文件不能再打开。

第 13 版所有节点都未强制上传凭证；有证明需要时仍应主动上传。图片、视频和文件预览表现会受微信客户端支持情况影响，重要资料应及时另行保管。

### 审核人怎么做

从首页「待我审核」打开对应记录，核对售后编号、处理说明、字段快照与凭证。正确则点「通过」；需要补充或更正则填写明确原因再点「驳回」。发起人收到驳回后回到「待我处理」修正并重新提交。审核通过才会进入方案提供节点；能查看记录不等于有权处理或审核。

## 5 查找记录查看通知与导出

### 查找售后

从首页「查看全部」进入检索，输入售后编号的一部分、商品型号、订单号或已录入字段内容，再点「检索」。也可按创建日期缩小范围；无结果时先检查日期范围以及是否仍处于“已完成”等状态入口。

「进行中」「已完成」入口会直接显示当前账号可看的对应售后。搜索只能返回有权限的记录；搜不到不一定是不存在。搜索字段内容不等于能识别图片或视频里面的文字。

列表卡片只显示模板选定的摘要字段；查看完整商品属性、客户信息和反馈，应进入详情及节点记录。卡片摘要暂不可用时，也可先进入详情核对。

### 消息通知在哪里

首页「消息通知」是小程序内通知，打开条目可查看对应售后，也可「标记已读」。工作时主动检查「待我处理」「待我审核」及节点截止时间。

截至本说明核对日，尚未接通个人微信订阅消息或企业微信推送。不要依赖微信聊天窗口或“服务通知”提醒，也不要认为同意一次订阅就会永久每小时提醒。

### 运营看板和文件导出

1. 从首页「运营看板」进入，选择「45minup售后」和日期范围，按需要展开高级筛选。
2. 点击「生成统计图表」，查看处理／审核耗时，以及「节点字段选项统计」。
3. 字段统计按节点完成日期取最终有效结果，只在看板展示单选、多选的选项次数；保存次数不是出现次数。多选一次勾选多个选项时，各选项分别计数。
4. CSV 导出为超级管理员功能。看到「导出 CSV」按钮时，先点击生成，等待按钮变成「发送 CSV」，再点一次打开微信文件发送窗口，自行选择接收位置。

CSV 同时包含运营基础、全字段明细和选项统计；文本、日期等其他字段在导出中查看。运营基础按售后创建日期，字段部分按节点完成日期，因此同一日期范围下两类样本数量可能不同。普通员工没有导出按钮属于权限限制，不需要反复点击。

### 分享和保密

只有需要对外提供某节点结果时，才考虑「生成固定分享快照」；它不是保存进度，也不是提交审核。生成前确认有分享权限，并核对快照内的客户姓名、电话、地址及凭证是否允许给接收方查看。

不要把售后记录、客户信息或 CSV 发到无关群聊。共享设备使用完后，到「个人资料」退出账号；忘记密码或账号权限异常交由管理员处理。

## 6 常见问题与首次使用检查

### 我为什么不能填写这个节点

先看当前账号是否为页面显示的处理人，以及该节点是否已轮到处理。待审核、已完成或已冻结的内容可能只读；审核人应从「待我审核」操作，不是在处理人表单里修改资料。仍有疑问时，把售后编号、节点名称及报错截图发给管理员。

### 为什么没有后面的属性或 SN

字段按分类、品牌、型号及已选属性逐级出现；并非每个商品都有五个属性。SN 也有显示条件。只填写当前可见的必填项；应有而没有时，先复查前面的选择，再请管理员核对模板，不能任意代填。

### 为什么保存了还没到下一步

「保存处理进度」只保存内容。信息收集还需要「提交审核」并通过；其他节点要由处理人点击「完成节点」。可以返回详情查看当前状态确认卡在哪一步。

### 提交后无反馈或者提示网络异常怎么办

先保留页面，查看进度与错误提示；不要连续重复创建或提交。网络恢复后返回列表或详情确认服务端状态，再决定是否重试。若页面明确提示“再次点击提交审核确认结果”，按该提示操作。向管理员提供发生时间、使用设备、售后编号和截图，不要提供账号密码。

### 方案选错或者售后已经完成怎么办

完成前重新核对「解决方案」与「配件是否退回」，因为它们决定后续路线。节点完成或整条售后冻结后，普通员工不能随意回改；联系管理员判断是否需要受控修订，不要另建重复售后来覆盖错误。

### 凭证打不开或者统计没有样本怎么办

凭证先检查是否已登记、是否标记为已清理，以及当前账号是否有查看权限；保留文件名及报错截图反馈。看板先核对模板、日期、状态和节点筛选；未完成节点的过程保存不会直接成为最终字段统计样本。仍异常时交管理员核查，不要重新造数据“补样本”。

### 首次使用完成后自查

- 登录姓名是本人，已完成首次改密，没有共用同事账号。
- 创建时选的是「45minup售后」，知道在哪里查看售后编号。
- 商品分类、品牌、型号及适用属性匹配，订单及联系方式已核对。
- 当前可见必填项已填齐，凭证操作收到成功反馈。
- 知道保存不等于提交；能在详情确认当前节点及待审核／完成状态。
- 知道去「待我处理」「待我审核」「消息通知」查看任务，不等待外部微信推送。
